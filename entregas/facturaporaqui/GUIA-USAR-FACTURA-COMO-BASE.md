# Crear otra factura sin volver a ingresar sus productos

1. En **Comprobantes Electrónicos → Facturas emitidas**, busca la factura cuyos productos quieres reutilizar.
2. Abre **Opciones → Usar como base para otra factura**.
3. Selecciona el cliente de la nueva factura. Puedes crearlo allí mismo si tu perfil tiene permiso.
4. Revisa productos, cantidades, precios, descuentos y el punto de emisión. Los avisos señalan falta de stock o cambios de tarifa/precio.
5. Completa el pago y revisa el total. Cuando esté correcto, pulsa **Emitir factura**.

La factura original se conserva. Abrir esta opción o cancelar no crea otra factura ni consume un número. El número mostrado es orientativo: el sistema asigna el definitivo al emitir, siguiendo la secuencia del punto activo.

Con permiso para cambiar precios se conserva el precio de la factura original. Los demás perfiles utilizan el precio vigente del catálogo o de la promoción; la pantalla avisa cuando cambia. El catálogo de productos no se modifica por cambiar el precio de una línea.

El cliente, los datos adicionales, los cobros, las notas y los archivos de respaldo no se copian. Revisa esos datos para cada nueva venta. Si no termina la carga, utiliza **Reintentar la carga** o **Empezar una factura vacía**. Cambiar de empresa exige volver al listado de esa empresa y elegir allí la factura de origen.

## Identificación del servicio en los impresos

El RUC de FacturaPorAquí aparece en el pie, junto a los datos del proveedor del servicio, sin repetirse en «Información adicional». El RUC del negocio que emite la factura sigue en el encabezado.

Los PDF guardados antes de publicar este cambio mantienen su presentación hasta que se regeneren. Esta actualización visual no altera la clave, el número ni el XML autorizado de un comprobante.
